# Multi-FASTA Sequence Analyzer — Complete Research Suite

A professional Streamlit sequence-analysis platform covering FASTA QC,
sequence composition, visualization, ORFs, motifs, k-mers, codons, restriction
sites, primer screening, pairwise comparison, MSA, consensus, conservation,
variants, distance matrices, clustering, identity matrices, sequence utilities,
CpG/dinucleotide analysis and protein analysis.

## Major modules

- FASTA validation and duplicate detection
- DNA/RNA sequence utilities
- Sequence statistics and QC scoring
- GC/AT/skew and entropy profiles
- Motif and regex screening
- k-mer and codon analysis
- Restriction-site analysis
- ORF and six-frame translation
- Primer/oligo screening
- Pairwise identity and difference matrices
- Lightweight progressive MSA and consensus
- Conservation analysis
- Variant/SNP comparison
- Distance matrix and UPGMA-style clustering
- CpG and dinucleotide analysis
- Codon-position composition
- Protein composition and approximate molecular weight
- Interactive charts and heatmaps
- Automated research report
- CSV, Excel and FASTA exports

## Run locally

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Scientific scope

This application is designed for educational, exploratory and research-screening
work. Alignment, clustering, primer Tm, QC scoring and protein-property values
should be validated with specialist tools before publication or clinical use.
